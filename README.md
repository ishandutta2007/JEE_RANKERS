# JEE_RANKERS

This repository contains rank lists for selected students from the IIT JEE examinations across multiple years. The data is stored as plain text files and includes the candidate's rank, name, category, and registration number.

## Repository contents

- `2012` — IIT JEE 2012 selected students list
- `2013` — IIT JEE 2013 selected students list
- `2014` — IIT JEE 2014 selected students list
- `2015` — IIT JEE 2015 selected students list

## Data format

Each file contains entries in a simple tabular format such as:

```text
IIT JEE 2012 complete list of selected students(By name , roll no , rank)

Rank Name Category Registration No.
1 ARPIT AGRAWAL GE 2081376
2 BIJOY SINGH KOCHAR GE 7011281
3 NISHANTH N KOUSHIK GE 5023208
